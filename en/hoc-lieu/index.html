Access policy

Public documents

The learning resources catalogue and public documents can be viewed freely, without signing ing in. Each item states its source and the date it was updated.

Documents for students

Available only through ULAW’s official single sign-on (SSO/OIDC), with the server checking permissions before returning any file. Restricted files are not placed in public folders and do not appear in search results.
